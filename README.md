# Factorly Homebrew tap

[Factorly](https://github.com/factorly-dev/factorly) — a local runtime for agent tool chains. It manages tool calls, injects credentials from an encrypted vault, enforces governance rules, and logs everything. Your agent sees workflows, tools, and data. Secrets stay secret.

## Install

```bash
brew install factorly-dev/tap/factorly
```

Or, more explicitly:

```bash
brew tap factorly-dev/tap
brew install factorly
```

Then:

```bash
factorly version
factorly init
```

See the [getting started guide](https://github.com/factorly-dev/factorly/blob/main/docs/getting-started.md) for next steps.

## What's here

This repo holds one Homebrew formula:

- `Formula/factorly.rb` — pinned to the latest factorly release on each tag push. Auto-generated by [`brew/update-tap.sh`](https://github.com/factorly-dev/factorly/blob/main/brew/update-tap.sh) in the main repo.

The formula installs a prebuilt binary from the [GitHub Release](https://github.com/factorly-dev/factorly/releases) matching the user's OS and architecture (macOS amd64/arm64, Linux amd64/arm64). Windows users — install via [npm](https://www.npmjs.com/package/factorly), [pip](https://pypi.org/project/factorly/), or grab the `.exe` from the releases page directly.

## Updating

The formula updates automatically when a new factorly version is tagged. To force a re-install of the latest:

```bash
brew update
brew upgrade factorly
```
